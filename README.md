# MDRN examples

Example apps for [MDRN](https://mdrn.io), one per folder, each ready to deploy without edits.
Start from one in the MDRN console, with `mdrn init my-app --example <folder name>`, or copy its folder.
Each is MIT licensed; its README says what it shows and how to run it.

| Example | What it is | Uses |
| --- | --- | --- |
| [SaaS starter](saas-starter/) | Sign-in, teams and settings, with Postgres once live and SQLite in build mode. | Auth, Postgres, SQLite, Mail |
| [API with file uploads](files-api/) | A backend for a web or mobile app: per-user records, uploads and downloads, mail. | Auth, SQLite, Objects, Mail |
| [Link shortener](link-shortener/) | Short links with sign-in and SQLite. An AI agent wrote it from one prompt, and the prompt is included. | SQLite |

This repository is published from MDRN's own; a change made here is replaced by the next update.
